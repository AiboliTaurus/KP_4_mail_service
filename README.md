# 📧 Сервис управления рассылками

Веб-приложение на Django для управления email-рассылками, позволяющее создавать, отправлять и отслеживать рассылки, управлять получателями и сообщениями.

---

## 🚀 Возможности

### 👤 Пользователи
- Регистрация и аутентификация по email
- Редактирование профиля (аватар, телефон, страна)
- Приветственное письмо при регистрации

### 📨 Управление рассылками
- **CRUD** операции для сообщений, получателей и рассылок
- Динамическое обновление статуса рассылки (Создана → Запущена → Завершена)
- Валидация дат (start_time не может быть в прошлом, start_time < end_time)

### 📊 Статистика
- Отображение на главной странице:
  - Общее количество рассылок
  - Количество активных рассылок
  - Количество уникальных получателей
- Страница истории отправок с фильтрацией по статусу
- Статистика успешных/неудачных попыток для каждого пользователя

### 🔐 Права доступа
- Пользователи видят только свои рассылки, сообщения и получателей
- Группа "Менеджеры" с правами:
  - Просмотр всех рассылок, сообщений и получателей
  - Блокировка пользователей
  - Отключение рассылок

### ⚡ Кеширование
- Серверное кеширование через Redis
- Кеширование статистики главной страницы (5 минут)
- Кеширование списков рассылок, сообщений, получателей для каждого пользователя

### 📧 Отправка писем
- Отправка через интерфейс (кнопка "Отправить сейчас")
- Отправка через командную строку (`python manage.py send_mailings`)
- Сохранение истории попыток (статус, ответ сервера)

## 🛠 Технологический стек

| Компонент | Технология |
|-----------|------------|
| **Backend** | Django 6.0.2 |
| **База данных** | PostgreSQL |
| **Кеширование** | Redis + django-redis |
| **Почтовый сервер** | Yandex SMTP |
| **Frontend** | Bootstrap 5, HTML/CSS |
| **Язык** | Python 3.11+ |
